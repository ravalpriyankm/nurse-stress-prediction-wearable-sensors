# Historical scripts and notebook

These files come from the original **University of Essex CE888: Data Science and Decision Making module project**, undertaken during the **2022–2023 academic year**. They are retained only to preserve provenance.

**They are not part of the maintained pipeline.** They contain archived, non-portable Windows paths (with the local username anonymised), legacy data assumptions and row-level model evaluation likely to overestimate generalisation to new participants. Notebook outputs were cleared, and hard-coded personal-directory roots were generalised in the archived notebook.

Use `python -m nurse_stress` and the current README for supported workflows.
