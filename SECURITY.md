# Security and privacy

Please avoid opening public GitHub issues containing credentials, secrets or individual physiological records. Report security-sensitive concerns privately to the repository maintainer through GitHub's private vulnerability reporting if enabled, or the contact method supplied on the maintainer's GitHub profile.

All commands run locally; the software does not transmit recordings or survey data. The provided ZIP extraction command rejects path traversal and symlinks, but it is meant for the verified study archive, not general-purpose adversarial archive processing. Process unfamiliar archives in a sandbox.

This is research code, not a certified clinical, occupational or security product.
